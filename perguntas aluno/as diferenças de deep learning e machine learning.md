# as diferenças de deep learning e  machine learning

## Resposta

**Machine learning (aprendizado de máquina)** é uma área em que programas aprendem padrões a partir de dados para fazer previsões ou tomar decisões. **Deep learning (aprendizado profundo)** é um tipo de machine learning que usa redes neurais com várias camadas para aprender esses padrões.

A principal diferença está em **como o modelo aprende a representar os dados**. Em muitos métodos de machine learning, uma pessoa escolhe quais informações serão usadas pelo modelo. Por exemplo, para identificar spam, ela pode fornecer a quantidade de links e certas palavras de um e-mail. No deep learning, uma rede pode aprender representações úteis diretamente dos dados, embora ainda precise de preparo dos dados e de escolhas feitas por pessoas.

O deep learning costuma ser especialmente útil para **imagens, áudio e texto**, mas frequentemente precisa de mais dados e poder de processamento. Métodos mais simples de machine learning podem funcionar muito bem com **tabelas de dados**, especialmente quando há menos exemplos, e costumam ser mais fáceis de treinar e interpretar.

Em resumo: **todo deep learning é machine learning, mas nem todo machine learning é deep learning**. A melhor escolha depende do problema, da quantidade de dados e dos recursos disponíveis.
